# SafeHer - Women Safety & Emergency Alert System

## 🚀 Project Overview
SafeHer is a comprehensive women safety platform that provides instant SOS alerts, live location sharing, and emergency contact notifications. The backend is built with Node.js, Express.js, and MongoDB, following professional MERN development practices.

## ✨ Features
- 🔐 **Authentication**: JWT-based authentication with bcrypt password hashing
- 👤 **User Management**: Register, login, profile management, password change
- 📞 **Emergency Contacts**: CRUD operations with primary contact designation
- 🚨 **SOS System**: Instant emergency alerts with GPS location
- 📧 **Notifications**: Email and SMS notifications for emergency contacts
- 🔔 **Notification System**: In-app notifications with read/unread status
- 👑 **Admin Dashboard**: Complete admin panel with statistics and management
- 🔒 **Security**: Role-based authorization, input validation, error handling

## 🛠️ Technologies Used
- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **MongoDB** - Database
- **Mongoose** - ODM for MongoDB
- **JWT** - Authentication
- **bcryptjs** - Password hashing
- **Express-validator** - Input validation
- **Nodemailer** - Email service
- **Twilio** - SMS service
